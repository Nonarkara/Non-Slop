One install, one file per tool

install.sh, or npx init, writes .non-slop and a pointer. An existing pointer is appended once. Your own text stays.

What each tool actually reads
ToolFile
Claude CodeCLAUDE.md, and an optional PostToolUse hook
CodexAGENTS.md. No separate file.
Cursor.cursor/rules/non-slop.mdc
Copilot.github/copilot-instructions.md
Windsurf.windsurf/rules/non-slop.md
GeminiGEMINI.md
Any agentAGENTS.md
slop-lintpalette, tools/slop-lint.mjs, on a URL

The scanner in this repo is node bin/non-slop.mjs scan, and render for a live page. slop-lint is the sibling in Nonarkara/palette. Same rendered thresholds: 6 or more is SLOP, 3 to 5 is REVIEW, under 3 is OK.

Codex reads AGENTS.md and needs no extra file. Cursor gets .cursor/rules/non-slop.mdc, and an existing copy of that file is left as you wrote it. Claude can also run the scan from a PostToolUse hook.
